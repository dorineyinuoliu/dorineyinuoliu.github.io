Video game sales database

Turning a flat Kaggle file of game sales and review scores into a relational MySQL database, then using SQL to answer market questions.

Type
Solo course project
Course
SI 564 SQL & Databases, University of Michigan
Timeline
March–April 2026
Data
Kaggle video game sales and ratings data
Tools
Python for cleaning, MySQL, SQL

The question

The source data mixed games, platforms, genres, publishers, regional sales and review scores in one file. The job was to model it properly and then use it to answer market questions.

Data and methods

  • Cleaned the Kaggle sales and ratings data in Python.
  • Split it by entity into seven tables, including games, platforms, genres and publishers, and loaded 16,717 game records into MySQL.
  • Answered six market questions with joins, GROUP BY / HAVING and subqueries.

What I found

  • Of 580 publishers, only 4 sold more than 50 million units in each of North America, Europe and Japan.
  • Games rated 85 or higher averaged about 6.2 times the sales of games rated below 70.

Only about half of the games had ratings, so the second finding covers that half, and it's a correlation, not proof that ratings drive sales.

I presented the results as a business proposal letter and an in-class presentation.
